## How to Set Up the 3-Level Mega Menu in Shopify Admin

1. Go to **Online Store → Navigation → Main menu**.
2. Click **Add menu item**:
   * Name: `Smartphones` → Link: Collections → `Smartphones & Mobile Devices`
3. Click **Add menu item** again:
   * Name: `Apple iPhone` → Link: Collections → `Apple iPhone`
   * **Drag and drop** this item slightly to the right under `Smartphones` to indent it into Level 2.
4. Click **Add menu item** under `Apple iPhone`:
   * Name: `iPhone 16 Series` → Link: Collections → `iPhone 16 Series`
   * **Drag and drop** this item slightly to the right under `Apple iPhone` to indent it into Level 3.
5. Repeat for each branch! Shopify's modern Horizon theme engine will automatically render this nested hierarchy as a sleek multi-column dropdown mega menu.
